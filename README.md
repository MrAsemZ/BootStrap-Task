# Web Developer Landing Page

A simple responsive landing page built with **HTML, CSS, and Bootstrap 5**.

## Technologies

* HTML5
* CSS3
* Bootstrap 5.3.2

## Features

* Responsive design
* Navigation bar
* Web Developer hero section
* Developer image
* Three-step section
* Custom CSS styling

## How to Run

Download the project and open `index.html` in your browser.

Make sure the `media` folder contains:

* `logo.png`
* `developer.jpg`
